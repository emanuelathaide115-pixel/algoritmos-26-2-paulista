# Cupons promocionais

Durante a finalização de uma compra, o sistema aceita um cupom opcional. Basta digitar o código quando solicitado; pressione Enter para concluir sem desconto.

| Código | Desconto |
| --- | ---: |
| `MERCADO5` | 5% |
| `CLIENTE10` | 10% |

Cupons desconhecidos não bloqueiam a compra: ela continua sem desconto. O resumo da compra informa o desconto aplicado e o total final; esse total final é o valor registrado em `vendas.csv`.
